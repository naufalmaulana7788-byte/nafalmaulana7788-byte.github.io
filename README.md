# VALLShop

Template website toko online responsif dengan **5 halaman HTML terpisah**, satu file CSS, dan satu file JavaScript. Cocok untuk GitHub Pages.

## Struktur file

```text
VALLShop/
├── index.html
├── kategori.html
├── produk.html
├── tentang.html
├── kontak.html
├── style.css
├── script.js
└── README.md
```
